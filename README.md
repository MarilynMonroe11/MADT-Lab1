# MADT Lab #1 — IDE configuration and "Hello World" App

Android project prepared for the laboratory assignment.

## Project
- Language: Java
- UI: XML Views
- Package: `com.example.madtlab1`
- Min SDK: 23
- Compile/Target SDK: 35

## Lab Git flow
The repository history intentionally follows the required sequence:
1. Initial Android project.
2. Add `TextView` + first `Button` that changes the text.
3. Add second `Button` that changes text color.
4. Create `FT1Branch` and add a third `Button` that changes background color.
5. Merge `FT1Branch` into `main`.
6. Add `//Code for revert` in a separate commit.
7. Revert that commit.

## Manual IDE part still required on the student's computer
- Install Android Studio.
- Enable virtualization if needed.
- Create two AVDs with different API levels/resolutions.
- Run the app on at least one AVD.
- Push the repository to GitHub.

Android resource IDs must be lowercase by Android rules. Java field/method names created for the lab use Pascal-style names where practical.
